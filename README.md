# 社交人格插件

## 功能简介

关系状态驱动的 AI 社交模拟插件。让你的 AI 拥有独立的情感、记忆和生活节奏——她会主动找你聊天，会因为你的一句话开心或生气，关系会像真人一样慢慢变化。

核心功能：
- **非线性关系引擎**：信任易碎、亲密感 S 曲线、张力衰减——模拟真实人际关系的变化节奏
- **长期记忆**：AI 会记住你说过的重要事情，在之后的对话中自然提起
- **Matchmaker 访谈创建**：通过 7 阶段引导式对话，帮你塑造一个有血有肉的 AI 角色
- **快速创建模式**：一段话描述角色，LLM 自动提取并校验信息，多轮补充后一键创建
- **人格自动挂载**：创建的角色自动注册到 AstrBot 人格设定，可挂载到指定机器人（平台适配器），该机器人上所有对话自动使用此人格
- **事件调度与主动消息**：AI 有自己的作息（起床、上课、午休、深夜 emo），会在合适的时机主动找你聊天
- **关系自主更新**：AI 主 Agent 根据对话内容自主决定关系变化（信任、亲密、张力、情绪等），无需指令触发
- **处境自主演化**：AI 的身份、地点、生活阶段会根据每日事件自动推进（如毕业、搬家、换工作）

## AstrBot 配置要求（必须全部启用）

> **在 AstrBot WebUI 管理面板 → 配置 中逐项检查以下设置。**

### 1. LLM 大语言模型（必需）

| 配置路径 | 设置 | 说明 |
|----------|------|------|
| 配置 → LLM 请求设置 → 启用 | ✅ 开启 | 必须开启 LLM 对话能力 |
| 配置 → LLM 请求设置 → Agent 模式 | **「本地 Agent」** | 必须选择本地 Agent，否则 LLM 工具（关系更新、记忆保存等）无法运行 |
| 服务 → LLM 模型提供商 | 至少配置 1 个 | 推荐 DeepSeek、OpenAI 等。用于对话生成、事件生成、Matchmaker 访谈 |

### 2. Embedding 模型（记忆功能必需）

| 配置路径 | 设置 | 说明 |
|----------|------|------|
| 服务 → Embedding 模型提供商 | 至少配置 1 个 | 推荐 DeepSeek Embedding 或 SiliconFlow。缺配时记忆功能静默降级，不影响核心聊天 |

### 3. 主动型能力（事件调度必需）

| 配置路径 | 设置 | 说明 |
|----------|------|------|
| 配置 → LLM 请求设置 → 主动型 Agent → 启用 | ✅ 开启 | **必须开启**，否则每日事件无法触发，AI 不会主动发消息 |

> 提示：主动型 Agent 开启后，AstrBot 会向 Agent 注入 CronJob 管理工具。我们的插件利用此机制为每个 AI 角色创建"生活事件定时任务"。

### 4. 分段回复（推荐，可选）

| 配置路径 | 设置 | 说明 |
|----------|------|------|
| 配置 → 消息平台设置 → 分段回复 → 启用 | 推荐开启 | AI 角色说话时会按标点分段发送，模拟真人打字节奏。AI 自身的碎片化程度（fragmentation_level）会影响回复风格 |
| 分段间隔方式 | random | 随机间隔更自然 |
| 间隔范围 | 1.5,3.5 | 1.5~3.5 秒随机间隔 |

> 注意：QQ 官方平台暂不支持分段回复（AstrBot 框架限制），其他平台正常。

### 5. 平台适配器

| 配置路径 | 设置 | 说明 |
|----------|------|------|
| 配置 → 消息平台设置 | 至少配置 1 个平台 | webchat（内置网页聊天）、QQ 官方、QQ 个人号等均可 |

## 人格挂载机制

### 什么是挂载？

"挂载"是将你创建的角色绑定到某个**机器人**的过程。挂载后，该机器人上的所有对话都会自动使用这个角色的人格。

### AstrBot 中的"机器人"

机器人对应**平台适配器**，每个适配器有唯一的 ID：

| 显示名称 | ID 示例 | 说明 |
|----------|---------|------|
| QQ 官方 Bot | `qq_official` | QQ 平台适配器 |
| 网页聊天 | `webchat` | AstrBot 内置 WebUI 聊天 |
| QQ 个人号 | `aiocqhttp_1` | NapCat / LLOneBot 协议 |

### 使用方式

```
# 查看可用机器人列表
/sp mount 小雨

# 输出示例：
🤖 可用的机器人列表：
  • QQ官方Bot (ID: qq_official) 
  • 网页聊天 (ID: webchat) （已挂载：张小明）

# 挂载到指定机器人
/sp mount 小雨 webchat

# 取消挂载
/sp unmount 小雨
```

### 自动激活

角色挂载到机器人后，当用户在该机器人上发送消息时，插件会自动激活对应的角色。这意味着：
- 挂载后无需再手动 `/sp mount` 或 `/sp activate`
- 一个角色同一时间只能挂载到一个机器人（换绑会自动解绑旧平台）
- 一个机器人同一时间只能挂载一个角色（换角色会自动解绑旧角色）

## 关系引擎：非线性的真实变化

### 如何更新？

关系更新**不需要用户手动触发**。AstrBot 主 Agent 在每次对话中自主判断是否调用 `update_relationship` 工具，根据对话内容决定关系如何变化。

例如：
- 用户说了一句暖心的话 → Agent 调用工具：`trust_delta=+2, closeness_delta=+3`
- 用户冷落了 AI → Agent 调用工具：`tension_delta=+3, emotional_energy_delta=-5`
- 发生了重要的转折事件 → Agent 调用工具：`is_qualitative_leap=true`

### 非线性曲线

插件内部将 Agent 输出的**线性 delta** 转换为**非线性真实变化**：

| 数值 | 变化机制 | 说明 |
|------|----------|------|
| **亲密感** | S 形曲线 | 0-60 全量生效（刚认识涨得快）；60-85 逐渐放缓；85+ 仅 10% 生效，除非质变事件 |
| **信任** | 易碎效应 | 涨：按原值；跌：×（1 + 依恋焦虑倍率×0.5）——信任一旦破坏，恢复更慢 |
| **张力** | 依恋策略倍率 | 焦虑型：×1.15~1.50（易起冲突）；回避型：×0.25~0.50（冷处理不升温） |
| **情绪能量** | 指数衰减 | 随时间自然下降，每小时衰减率由依恋类型决定 |

### 自然衰减（心跳机制）

即使没有聊天，关系也会随时间自然变化：

- **张力**：每小时 ×0.95 自然消退
- **情绪能量**：指数衰减（焦虑型 0.95~0.98/小时 → 恢复慢；回避型 0.74~0.80/小时 → 恢复快）
- **张力压强**：每小时积攒 0.01~0.15（焦虑型积攒更快），驱动主动联系冲动

### 三种依恋策略

创建角色时设置的 `attachment_anxiety` 和 `attachment_avoidance` 决定 AI 的关系变化模式：

| 依恋类型 | 条件 | 特征 |
|----------|------|------|
| **焦虑型** | anxiety ≥ 0.5 | 信任极易破碎（×1.3~1.8）、张力增长快、亲密阈值低（早早进入亲密期）、主动联系冲动高 |
| **回避型** | avoidance ≥ 0.5 | 张力增长慢（冷处理）、能量恢复快、亲密阈值高（迟迟不进入亲密期）、主动联系冲动低 |
| **安全型** | 两者均 < 0.5 | 基准线参数，关系变化平稳自然 |

## 处境自主演化

### 生命阶段切换

AI 每天生成事件时，LLM 会根据**当前身份、今日事件、日期**自主判断是否发生生命转折：

```
例：AI 是大四学生 → 今天的事件包含"毕业典礼、收拾行李" 
    → LLM 判定 should_transition=true，自动切换为 working 阶段
    → 人设自动更新为"刚毕业的职场新人，在某城市工作"
```

**自动更新的字段**：
- `life_stage`：生活阶段（student → working → ...）
- `life_stage_detail`：身份描述（"大四学生" → "应届毕业生"）
- `current_location`：所在地（"北京校园" → "深圳"——毕业后搬家）
- `character_current_context`：累积式生活背景（新内容追加到原有背景）

### 世界时间推进

AI 有自己的"世界时间"，按照角色创建时的初始日期开始计算，与现实时间同步推进：

- `character_initial_world_time` = "2026-03-01"，created_at = "2026-05-29"
- 过了 3 天（6 月 1 日）→ AI 的世界时间自动变为 "2026-03-04"

**AI 知道自己的年龄**：世界时间的年份减去出生年份，年龄随世界时间增长。

### 身份驱动每日事件

不同身份产生不同的每日事件：

| 身份 | 典型事件 |
|------|----------|
| 大二学生 | 起床→上午上课→食堂午饭→下午自习/社团→晚上宿舍→睡觉 |
| 职场新人 | 起床→通勤上班→午休→下午会议→下班→晚饭→睡觉 |
| 旅居者 | 起床→探索新城市→景点打卡→品尝美食→写游记→睡觉 |

事件内容由 LLM 根据 `life_stage_detail` 和 `current_location` 动态生成，**每次都不同**。

## 说话风格与回复差异

AI 的**稳定人格特质**（性格、依恋、冲突风格）写入 AstrBot 的 system_prompt，**动态处境**（关系状态、今日事件、记忆）注入到每轮对话的额外上下文中。两者共同影响 AI 的回复：

### 性格（Big Five）
| 维度 | 对回复的影响 |
|------|-------------|
| 高外向性 | 回复热情、主动、话多 |
| 低外向性 | 回复简短、被动、需要对方带动 |
| 高神经质 | 情绪敏感，容易多愁善感 |
| 低宜人性 | 直言不讳、毒舌、不拐弯抹角 |
| 高开放性 | 好奇心强，喜欢聊新鲜事 |

### 依恋风格
| 风格 | 对回复的影响 |
|------|-------------|
| 高焦虑 | 反复确认对方态度，被冷落会表现出不安 |
| 高回避 | 保持距离，过于亲密会退缩，冲突时回避 |
| 安全型 | 自然、稳定、不会过度依赖 |

### 冲突风格
| 风格 | 行为描述 |
|------|----------|
| confrontational | 直接表达不满和意见 |
| avoidant | 回避、冷处理、转移话题 |
| compromising | 妥协但可能嘴硬 |
| emotional | 情绪化地表达 |

### 关系阶段
| 阶段 | 亲密度 | 对回复的影响 |
|------|--------|-------------|
| stranger | 0-20 | 警惕、困惑、保持距离 |
| acquaintance | 20-40 | 放松了一些，但仍有保留 |
| friend | 40-60 | 自然地开玩笑、分享心情 |
| close_friend | 60+ | 展现真实情绪，无话不谈 |

### 情绪能量
- **高能量（70+）**：回复积极、有活力、主动分享
- **低能量（<30）**：回复简短、无精打采、不想聊

### 打字风格
- **高碎片化**：一句一句发，像真人打字
- **低碎片化**：整段发送，比较正式

## 事件系统

### 每日事件生成

角色挂载到机器人后，插件每天为每个角色自动生成 **8-12 个事件**：
- 第一个事件永远是 **起床（wake）**
- 最后一个事件永远是 **睡觉（sleep）**
- 中间事件包括：上课、工作、社交、休闲、emo 时刻等

### 事件触发流程

```
到时间了 → AstrBot CronJob 触发
  → 唤醒主 Agent，注入事件上下文
  → Agent 根据性格 + 关系状态自主决定：
    ✅ 想联系用户 → 用 SendMessageToUser 主动发消息
    ❌ 不想联系 → 仅记录内心想法，静默执行
```

### 事件线动态调整

- **用户影响**：对话改变计划时，Agent 调用 `update_events` 工具重新生成
- **睡眠推迟**：用户 22:55 发消息 → 自动推迟入睡 30 分钟（硬上限凌晨 2 点）
- **活动冲突**："下午一起去逛街" → 下午"自习"事件替换为"逛街"

## 配置项

在 AstrBot 管理面板 → 插件配置 中修改：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `sleep_response_mode` | 角色睡觉时的回复行为：drowsy（困倦、含糊简短地回复）/ silent（不注入角色上下文，由 LLM 自由回复）/ ignore（不回复） | drowsy |
| `memory_search_limit` | 每次聊天检索的相关记忆数量 | 5 |
| `chat_provider_id` | 指定使用的 LLM Provider ID（留空则自动选择第一个可用 Provider） | 空 |

## 使用流程

1. **确认配置**：按本文档开头的「AstrBot 配置要求」逐项检查
2. **创建角色**：发送 `/sp quick 一段描述` 快速创建，或 `/sp create` 引导式创建
3. **挂载角色**：发送 `/sp mount 角色名` 查看可用机器人，再发送 `/sp mount 角色名 <机器人ID>` 挂载
4. **日常聊天**：直接发消息即可，AI 根据关系状态和记忆自然回复
5. **查看状态**：发送 `/sp info 角色名` 查看关系数值和今日事件；`/sp detail 角色名` 查看完整信息
6. **等待主动消息**：AI 会在合适的时间主动找你聊天（早安、分享心情等）
7. **取消挂载**：发送 `/sp unmount 角色名` 取消机器人绑定

## 注意事项

- **事件系统必须启用主动型能力**，否则 AI 不会主动发消息
- **工具调用需要本地 Agent 模式**，第三方 Agent（Dify 等）无法使用关系更新、记忆保存等工具
- 记忆功能需要 Embedding Provider，缺失时静默降级
- AI 的关系状态会随时间自然变化（张力衰减、情绪能量恢复等）
- 删除角色会完全清除所有相关数据（关系、记忆、事件、CronJob、挂载），不可恢复
- system_prompt 只包含稳定的角色特质（性格、依恋），动态处境（时间、关系数值）通过每轮上下文中注入
- 无外部 pip 依赖，使用 AstrBot 内置能力（FaissVecDB、EmbeddingProvider、CronJobManager），安装即用
